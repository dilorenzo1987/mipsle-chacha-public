# Results: GL-MG1300 (Mango 2), 2026-11-16

Device: MediaTek MT7621 (MIPS 1004Kc, MIPS32r2, 2 cores x 2 VPEs, 880 MHz), GL firmware 4.10.1, 128 MB RAM.
Base: tailscaled 1.104.7 tiny (admonstrator build, unpacked). Patched: same source/tags/flags + overlay
(`1.104.7-tiny.mipsle-chacha`, sha256 ba86097b8a1743b711be4b43c42f7b3978a01896881ef59085387de823930843).

## Crypto micro-benchmark (bench/main.go, 1 thread, 1420-byte packets)

| | pure Go | mipsle asm | OpenSSL 1.1.1t asm |
|---|---|---|---|
| ChaCha20 | 76.7 Mbit/s | 384 Mbit/s | – |
| Poly1305 | 156 Mbit/s | 1204 Mbit/s | – |
| ChaCha20-Poly1305 seal | 49.4 Mbit/s | 265 Mbit/s | 213 Mbit/s |
| ChaCha20-Poly1305 seal, 4 threads | 107 Mbit/s | 533 Mbit/s | 431 Mbit/s |

## End-to-end A/B (same session, binaries swapped back and forth, 2 runs each)

Router on home Wi-Fi (65 Mbit/s without Tailscale). "Exit" = via exit node over a direct UDP path to
speed.cloudflare.com; "DERP" = to a peer that is only reachable via a custom DERP relay (TLS 1.3 ChaCha20-Poly1305).

| | admon tiny | mipsle-chacha | gain |
|---|---|---|---|
| Exit download | 18.1 / 18.0 Mbit/s | 21.1 / 21.8 Mbit/s | +19 % |
| Exit upload | 14.5 / 14.9 Mbit/s | 17.7 / 18.1 Mbit/s | +22 % |
| DERP download | 7.1 / 7.2 Mbit/s | 11.3 / 11.0 Mbit/s | +56 % |

The relay path gains most because each packet is encrypted twice (WireGuard + TLS to the DERP server).
The remaining cost is per-packet work in tailscaled (TUN read/write syscalls, Go runtime, magicsock).
